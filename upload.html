Update the study hub

For GitHub, upload new HTML pages to the matching folder. Notes go in notes/; tests go in test/. Keep the shared assets folder in place.

Publishing steps

  1. Open your repository.
  2. Open the destination folder.
  3. Choose Add file → Upload files.
  4. Commit changes. Your host will redeploy the site.
