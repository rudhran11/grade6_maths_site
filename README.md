# Grade 6 Maths Study Hub

Static website based on the layout and interaction style of the Grade 8 Maths Study Hub reference. Content is for Grade 6 Ganita Prakash Chapter 6: Perimeter and Area. The interactive test includes **area only** (no perimeter questions).

## Run locally
Open `index.html` in a browser.

## Deploy
Upload the contents of `grade6_maths_site` to a GitHub repository and enable GitHub Pages, or import the repository into Vercel/Netlify.

## Structure
- `index.html` — homepage
- `notes/` — notes index and chapter notes
- `test/` — area-only interactive test
- `sessions/` — study sequence
- `upcoming-tests/` — future practice area
- `assets/` — shared stylesheet and JavaScript
